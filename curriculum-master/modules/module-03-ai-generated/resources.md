### Curated Resources
1. [3Blue1Brown - Essence of Neural Networks](https://www.youtube.com/watch?v=Ilg3gGewj0Y) - An intuitive video series explaining neural networks visually.
2. [Stanford CS231n: Convolutional Neural Networks for Visual Recognition](http://cs231n.stanford.edu/) - An in-depth course covering many aspects of deep learning.
3. [Deep Learning Book - Ian Goodfellow](https://www.deeplearningbook.org/) - A comprehensive resource with theoretical and practical approaches to deep learning.
4. [Python NumPy Documentation](https://numpy.org/doc/stable/) - Documentation for NumPy, a library for numerical computations that you'll be using heavily.
5. [Towards Data Science - Neural Network from Scratch in Python](https://towardsdatascience.com/neural-network-from-scratch-in-python-7fac3491ab0e) - A blog post detailing neural network construction and code.
6. [Khan Academy - Neural Networks and Deep Learning](https://www.khanacademy.org/computing/computer-programming/programming/algorithms/neural-networks) - Interactive tutorials on basics of neural networks.
7. [PyTorch Documentation](https://pytorch.org/docs/stable/index.html) - If you wish to explore neural network frameworks in Python.
