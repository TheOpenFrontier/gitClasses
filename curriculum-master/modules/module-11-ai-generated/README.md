# Module 11: Advanced Async Python

Welcome to Module 11 of gitClasses! In this module, we’ll dive into the thrilling world of asynchronous programming in Python, focusing on the `async` and `await` keywords, along with concurrent fetching. By the end of this module, you will gain a deeper understanding of how to write non-blocking code that allows for efficient I/O operations.

### Learning Objectives

By the end of this module, you should be able to:
- Understand the fundamentals of asynchronous programming in Python.
- Utilize `async` and `await` to write non-blocking functions.
- Fetch data concurrently using async functions to improve performance.
- Evaluate the benefits and trade-offs of using asynchronous programming.

### Path Descriptions

To accommodate different learning styles, we've prepared three paths for you to follow:

**Path A: Simply Async**  
In this path, you will focus on understanding and implementing basic async functions. You’ll write simple non-blocking code to get a feel for how it works.

**Path B: Concurrent Fetching Fun**  
This path will take you a step further by introducing concurrent fetching. You’ll implement asynchronous functions that fetch data from multiple sources simultaneously, enhancing your understanding of real-world applications of async programming.

**Path C: Community Contribution**  
For those who want to give back, this path not only involves implementation but also requires you to contribute to the community. You’ll document your findings, share insights, and help others understand asynchronous programming better.
